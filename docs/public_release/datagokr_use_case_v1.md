## 설명 (요약)

규제 담당 인력이 없는 중소기업이 물질 하나(이름 또는 CAS 번호)만 넣으면 다음을 한 화면에서 확인하고 체크리스트(인쇄·PDF·CSV)로 받습니다.

- KOSHA MSDS 16개 항목
- 국내 23개 법령 52개 지정 목록 등재 여부(화학물질관리법·화평법·산업안전보건법·대기·수질·토양·폐기물·위험물·고압가스·생활화학제품·화장품·농약·선박 위험물 등)와 근거 조문 원문
- 인허가·신고 56건(배출시설 설치허가, 영업허가, 공정안전보고서 등)과 실제 통합허가 처리기간
- 수입·수출 시 의무(세관장확인 대상 표시), 전략물자·화학무기·마약류 원료물질 해당 여부
- 상대국(EU·미국·중국·일본·베트남 등) 규제 목록, HS 품목번호 후보

무료이며 회원가입이 없습니다. 요청 게시판으로 받은 의견을 반영합니다. 법적 자문이 아니며 원문 확인을 안내합니다.

## 활용 목적

중소기업의 화학물질 규제 대응 부담 완화. 중소기업중앙회 조사(2026.4, 500개사)에서 등록 부담 1위가 "내부 인력 및 전문성 부족"이었다(언론 보도 기준, 원문 미확인 — 등록 전 원문 확인).
