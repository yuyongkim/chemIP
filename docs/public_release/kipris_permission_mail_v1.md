제목: [이용 허락 요청] KIPRIS Plus API 검색 결과의 무료 공개 서비스 표시

한국특허정보원 KIPRIS Plus 담당자님께

안녕하세요. 화학물질 안전·규제 정보를 통합 조회하는 무료 웹 서비스 ChemIP를 운영하는 김유용입니다.

KIPRIS Plus 이용약관 제19조와 저작권정책을 확인하였고, 아래 이용이 허락 대상인지 문의드리며 서면 허락을 요청드립니다.

[ 서비스 개요 ]

- 대상: 규제 담당 인력이 없는 중소기업 실무자
- 내용: 물질 하나(이름·CAS)로 MSDS, 국내외 규제 목록, 인허가·수출입 의무를 한 화면에 보여 줍니다.
- 운영 방식: 무료, 회원가입 없음, 광고 없음, 소스 코드 공개(AGPL-3.0)
- 주소: https://chemip.yule.pics/chemip/

[ 요청드리는 이용 범위 ]

1. 물질 화면의 특허 탭에서 KIPRIS Plus API 검색 결과(출원번호, 발명의 명칭, 출원인, 출원일, 요약 일부)를 목록으로 표시
2. 각 결과에 KIPRIS 원문 링크와 "출처: 한국특허정보원 KIPRIS Plus" 표시
3. 결과를 영구 저장하거나 재판매하지 않으며, 원문을 번역·재가공하지 않음
4. (선택) 물질별 요약 보고서에 출원 건수·출원인 등 통계를 참고로 인용 — 허락되지 않으면 제외하겠습니다.

현재는 허락 전이므로 특허 탭에 "KIPRIS에서 보기" 링크만 두고 검색 결과는 표시하지 않고 있습니다.

허락이 가능한 범위, 필요한 절차·서식, 출처 표시 문구를 알려 주시면 그대로 따르겠습니다.
