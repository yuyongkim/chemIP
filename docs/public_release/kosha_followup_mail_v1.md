당시 개인 프로젝트 수준이라고 말씀드렸던 ChemIP를 중소기업이 무료로 쓸 수 있는 공개 서비스로 정리하여 안내드립니다.

[ 무엇이 달라졌는지 ]

- 물질 하나(이름·CAS)를 넣으면 MSDS 16개 항목과 함께 국내 23개 법령 52개 지정 목록 등재 여부, 인허가·신고, 수출입 의무, 상대국 규제, HS 품목번호를 한 화면에 보여 드립니다.
- 확인 항목을 체크리스트(인쇄·PDF·CSV)로 내려받을 수 있습니다.
- 무료이며 회원가입이 없고, 소스 코드를 공개(AGPL-3.0)했습니다.
- 요청 게시판으로 중소기업 실무자의 의견을 받아 반영합니다.

[ 공단 MSDS OpenAPI 관련 ]

- MSDS 항목은 공단 OpenAPI 자료를 출처와 함께 표시하고, "법적 자문이 아니며 원문 확인 필요"를 안내합니다.
- 공개 운영을 위해 data.go.kr 활용사례 등록과 운영계정 신청을 준비하고 있습니다.
- 운영 중 확인한 자료 오류나 개선 의견이 있으면 data.go.kr 개선요청 경로로 전달드리겠습니다.
