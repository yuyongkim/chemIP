# 화공·엔지니어링 확장 딥리서치 종합 v1 (2026-10-31)

다섯 갈래 조사(원문: `docs/portal/research/R1~R5_*.md`)를 하나의 순위·로드맵으로 묶었다.
R1 해외 공학 포털 비교 · R2 무료 공학 자료원·라이선스 · R3 국내 수요 · R4 공정안전 도구 · R5 단위조작·설계.
원칙은 그대로: 무료·정적(R2/Pages)·브라우저 계산, PC 꺼져도 동작, EPC(두께·잔여수명·SIL/PFD·아크플래시)와 겹치지 않기.
검색량 수치는 로그인 장벽(Similarweb·네이버 데이터랩)으로 못 구해, 여러 사이트 공통 보유·포럼 글 수·시험 출제 근거로 순위를 매겼다.

## 1. 결론 한 줄

ChemIP 의 공백은 **화공 학부 핵심 과목(증기표·기액평형·증류·공정제어)** 과 **국내 실무 판정(적용 법규·장외영향 사전 검토)** 이다.
"안전·규제 자료 + 공학 계산"을 한국어로 묶은 사이트는 국내외 어디에도 없다(R1) — 이것이 차별점이다.

## 3. 만들지 않을 것

- **Dow F&EI·Mond 지수**: AIChE 저작권 표·곡선을 그대로 써야 함(R4).
- **LOPA**: EPC 의 SIL/PFD 와 겹침 → 링크만.
- **NIST WebBook·JANAF·REFPROP·DIPPR·Yaws·CRC·Perry 대량 복제**: 저작권/DB 제작자 권리(저작권법 제93조)(R2).
- **ISA 5.1 기호 그대로**: 저작권 + AI 파생물 금지 조항 → 태그 문자 규칙을 우리 말로 설명하는 정도만(R5).
- **KDB(구 cheric.org)**: 옛 도메인이 다른 사이트로 넘어감. ChemIP 에 링크 없음 확인(2026-10-31). 새 주소(mdlkdb.com)는 이용 조건이 없어 제휴 문의 전에는 쓰지 않는다.

## 4. 법적 표시 원칙

- 장외영향평가는 고시상 NICS 도구(KORA)로 해야 하고 다른 프로그램은 동등성 입증이 필요하다 → ChemIP 거리 계산은 모두 **"참고용 스크리닝"**, NICS 서식 흉내 금지.
- PSM 보고서·법정 작업환경측정·방폭 구역 구분은 법정 의무 → **"학습·사전 검토용"** 표시.
- 검증 숫자는 출처에 인쇄된 값([src])만 회귀 시험으로 쓰고, 손계산([calc])은 교과서 대조 후 쓴다(R4 표기 그대로).

## 5. 구현 순서 제안

1. 차트 모듈 → 단위 변환기 → 증기표·습공기 선도 (기반, 1주 이내 분량)
2. 화공기사 실기 묶음 + 공정제어 (학생 유입)
3. 누출량 → 장외영향 사전 검토 → 적용 법규 판정기 (실무자 유입, 국내 유일)
4. 화재·폭발·독성 → 혼합물 인화성 → 설비 사이징
5. 온도-물성 곡선(라이선스 허용 목록 먼저) → HAZOP·탱크 손실 → CoolProp·VLE
